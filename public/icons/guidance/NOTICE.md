# Guidance icons

Guidance by Streamline: https://streamlinehq.com/
Original set: https://site.streamlinehq.com/set/guidance

https://creativecommons.org/licenses/by/4.0/

Original standalone SVG files are preserved in this directory. The React rendering changes monochrome black to currentColor and adjusts stroke thickness for small controls and large cursors. Arrow aliases follow actual geometry because the upstream left/right filenames are reversed. External-link controls reuse the original diagonal arrow; no additional network requests occur when rendering icons. The source manifest records pinned upstream URLs.

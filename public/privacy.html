Privacy

Last updated 14 September 2026

What the product does

design / daily creates a shared daily briefing for a design team. It combines public web sources with newsletters received by a dedicated newsletter-only Gmail inbox.

Google data we access

The product uses Google OAuth with the read-only Gmail scope. It can read messages and mailbox settings in the connected account. It cannot send, modify, or delete email.

Access is used only to retrieve newsletter messages for the daily crawl. The connected account should contain newsletters only and should not be used for personal correspondence.

How data is processed

  • The scheduled crawler runs in GitHub Actions.
  • Relevant newsletter and web excerpts are sent to the OpenAI API to produce the editorial synthesis. OAuth credentials are never sent to OpenAI.
  • The resulting summaries, source titles, links, and provenance may be published in the public design / daily edition.
  • Raw Gmail message bodies are not committed to the repository or exposed in the website bundle.

Storage and retention

Google OAuth credentials are stored as encrypted GitHub Actions secrets. Generated daily editions are stored as versioned JSON in the public repository so the archive remains available. Raw newsletter messages are read during a crawl and are not retained by the application.

Services involved

The workflow relies on Google Gmail and OAuth, GitHub Actions and GitHub Pages, and the OpenAI API. Each provider processes data under its own terms and privacy policy.

Your control

You can revoke design / daily’s Gmail access at any time from your Google Account connections. Revoking access stops future inbox crawls. For questions, contact newsforrapha@gmail.com.
